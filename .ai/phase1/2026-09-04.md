## Artifact merge verification

The `website-binder` repository was inspected and shallow-cloned read-only at current `master` commit `2ddc364de3dba4f03b01a5604b2954cc5ded329d`.

Its converter writes notebook HTML to `converter/static/jupyter/nb/**/*.html`. The updated workflow therefore:

1. uploads the contents of `converter/static/jupyter` as the `notebooks` artifact;
2. downloads the VuePress artifact into `site`;
3. downloads the notebook artifact directly into `site/static/jupyter`;
4. checks the homepage, IFC WASM, IFC model, and a representative notebook before uploading the Pages artifact.

The real converter was run in a temporary Python 3.9.25 environment. It produced 13 notebook HTML files. A local simulation using the actual VuePress build and generated notebook tree produced a 16 MB merged site and passed all four workflow assertions.
