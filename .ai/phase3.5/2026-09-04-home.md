# Phase 3.5B 首页 HTML 与 hydration 修复报告 — 2026-09-04

Phase 3.5B 修复自定义首页的非法 HTML 根结构及由此引起的中英文首页 hydration mismatch，同时保持现有视觉、交互和响应式行为。本阶段没有开始主页视觉重做，也没有修改依赖版本、文章内容或产品功能。

状态：实现、自动验证、桌面与 390px 浏览器回归、首次 hydration 控制台捕获和独立只读审阅均已完成，由独立提交 `fix: repair home markup and hydration` 保存。

## 根因与方案

自定义 `Home.vue` 原本渲染：

```html
<main class="home">
  <body class="is-preload ...">...</body>
</main>
```

HTML 不允许 `<body>` 成为 `<main>` 的子元素。SSR 会输出该结构，但浏览器解析 HTML 时会忽略或重排第二个 `<body>`，导致客户端 VDOM 的首个子节点与浏览器 DOM 不一致。因此开发环境报告 `<body> cannot be child of <main>`，`/` 与 `/zh/` 首次 hydration 各出现一个 mismatch。

最小修复保留现有 `<main class="home">` 根，将内部 `<body>` 替换为块级 `<div class="home-shell">`。`is-preload` 与 `is-touch` 仍绑定在该独立 shell 上；这比把样式合并到 `.home` 更能保持原有内层 reset、字体、背景和外层 navbar padding 的级联边界。

`home.css` 中所有 13 处 `.home body` 依赖均精确迁移为 `.home .home-shell`，包括 preload、touch 和 1800px 字号规则；没有改动其他选择器或视觉值。

## 生命周期修复

首页仍使用 Vue 2 名称 `beforeDestroy`，在 Vue 3 中应使用 `beforeUnmount`。本阶段将该 hook 改为 `beforeUnmount`，保存并精确解绑本组件注册的 breakpoint handler，清理 100ms preload timer，并用卸载标记阻止动态 import 在组件离开后注册监听。Vue 3 官方迁移说明确认该 hook 的重命名：[Vue 3 migration guide](https://v3-migration.vuejs.org/breaking-changes/)。

Typed 选择器、locale watcher、Modal、ClientOnly、header/main/footer DOM 结构和 breakpoint 配置均未重构。
