# Phase 3.5A 官方 tabs 语法迁移报告 — 2026-09-04

Phase 3.5A 将文章中由本地预处理器兼容的旧 tabs 写法静态迁移为 VuePress 默认主题支持的官方 `@tab` 写法，并删除编译期兼容层。本阶段没有修改自定义首页、依赖版本或产品功能。

状态：实现、自动验证、浏览器回归和独立只读审阅均已通过，准备作为独立提交 `refactor: migrate markdown tabs to official syntax` 保存。

## 迁移依据与范围

VuePress 官方 Markdown Tab 插件使用 `::: tabs` 容器和 `@tab` 分隔面板；容器可以使用更多冒号，以便内容包含其他 container。默认主题已经集成该插件：[VuePress Markdown Tab](https://ecosystem.vuejs.press/plugins/markdown/markdown-tab.html)。因此继续维护编译前源码改写没有功能收益。

迁移前只读盘点得到：

- 21 个 Markdown 文件、43 个 tab group、111 个 tab item；
- 24 个 group 含代码块，共 58 个 code item；
- 10 个 group 含 Jupyter，共 28 个 Jupyter item；
- 4 个原本为空的 tab item 被原样保留；
- 10 个文件含多个 group，其中 `tree-traversal.md` 最多，为 8 组、24 个 item。

静态迁移规则为：保留外层 `:::: tabs` 和最终 `::::`，将每个 `::: tab TITLE` 改为 `@tab TITLE`，并删除该 item 自己的 `:::` 结束围栏。标题、顺序、正文、代码、Jupyter、表格和脚注均不改写。

## 实施内容

- 迁移上述 21 个 Markdown 文件的全部 43 组 tabs。
- 删除 `docs/.vuepress/markdown/legacyTabs.ts`。
- 删除 `docs/.vuepress/config.ts` 中 `legacyTabsPlugin` 的 import 和 `extendsMarkdown` 注册。
- 未修改 `Home.vue`、首页样式、依赖清单或构建配置。

迁移后用已删除转换器的原始算法对 `HEAD` 中的旧文件重新计算期望结果，再与当前文件逐字比较；21/21 文件完全一致。另一个只读审阅也独立确认 Markdown diff 恰好是 111 个 opener 替换和 111 个 item closer 删除，没有正文、标题、代码、顺序或 Jupyter 变化。
