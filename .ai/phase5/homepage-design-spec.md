更新：2026-11-23。用户认可“突出 AI 应用成果、项目链接降级、视觉更酷”的改版方向并授权完全重设计；英文 / 与中文 /zh/ 继续使用 Homepage 布局和全站共用导航。本版取代 A v2 的首屏规格，旧版可从 5b21b50 的 Git 历史查阅。

## 内容与行为

阅读顺序：首屏主张 → 01 现场演示 → 02 AI 服务架构 → 03 这个网站怎么造出来 → 04 联系。区块锚点 #lab、#ai-service、#engineering（导航“工程”）、#notes、#contact（导航“联系”）。

- 首屏：口号“One human. / Infinite agents.” / “一个人，/ 无限 Agent。”（2026-11-23 用户要求更口号化，替代较像解释的“Agents write the code. / I write the guardrails.”），与右侧 ∞ 呼应；说明句承接“AI 编码 agent 写代码，我写规格、测试和护栏”，再列出浏览器内模型、带登录与额度的大模型解释后端和本站。两个按钮跳到 #lab 与 #engineering。三项统计在构建时从检出目录计数（`.ai/**/*.md` 规格与决策记录、`scripts/` 与 `services/` 下的 check/test 脚本），不依赖 git 历史（CI 为浅克隆）；第三项为浏览器内模型测试准确率，读自 `lib/digits/meta.json`。
- 首屏视觉 HeroLoop：用 logo 路径作底，中心线 ∞ 上一束光循环流动，依次点亮 规格/生成/校验/上线 四站；站点时刻按贝塞尔弧长比例（0.129/0.371/0.629/0.871）同步。离开视口暂停动画。
- 现场演示：手写数字识别（大卡）+ 房贷比较（卡片）+ 税务入口 + 筛股器设计稿。筛股器明确标注“设计中 · 尚未实现”，示例 JSON 只表示目标效果。
- 手写识别：784→128→10 MLP，int8 按行对称量化，102,736 字节（`public/static/models/digits-mlp.bin`），接近视口时懒加载。笔画按 MNIST 方式归一化（20×20 外框、质心居中到 28×28）后推理，边写边更新；显示概率条、推理耗时和“模型看到的 28×28”。“试一个示例”绘制内置笔画，供键盘用户和自动化测试使用。不上传任何数据。
- AI 服务架构：六站（登录 PKCE、网关 JWT 与限流、Lambda 重算、DynamoDB 每日 20 次、Bedrock 调用、纯文本呈现）及护栏标签，事实来源为 ../ai-interpreter/architecture.md。Bedrock 站标注“权限开通中”。
- 工程区：规格 → agent 实现 → 机器校验 → 审阅上线四步，配 logo 贝塞尔蓝图（从 `/logo.svg` 路径解析锚点与控制柄，SSR 输出）。经历、开源链接与三条笔记收在同一区块；联系仍只有 Gmail、GitHub、LinkedIn，邮件链接唯一。
- 不虚构职位、业绩或线上状态；数字均来自仓库文件或训练脚本输出。

### AI 解释开关

2026-11-23 起正式上线：后端改用 Claude API（Opus 5.5，工作负载身份联合，无 API key），用户在 `?ai-preview=1` 下完成真实登录与解释验收后，`services/ai-interpreter/client/site-config.mjs` 的 `aiExplanationLive = true`。贷款卡片显示“AI 解释（需登录）”按钮，首页 AI 链路第 5 站为 CLAUDE API，不再标“接入中”。需要临时下线时改回 false；此时 `?ai-preview=1` 仍可在本机预览。

AI 解释面板（2026-11-23 用户选定方案 A + D）：点贷款卡的“✦ 问问 AI”打开右侧 480px 深色抽屉（手机为底部弹层，最高 88vh），Teleport 到 body，不再撑高贷款卡及同行的手写识别卡。抽屉为 `role="dialog"` + `aria-modal`，打开时锁定页面滚动、聚焦标题、Tab 循环在抽屉内，Esc/× /点遮罩关闭并把焦点还给触发按钮。头部：“问问这笔贷款”、标题、`Claude Opus 5.5` 与“今日剩余 n / 20”标签、当前参数标签（金额/利率/年限）。未登录时显示带主按钮的登录卡；三个问题为大号可选卡片，当前问题高亮；等待时显示跳动点与“停止等待”；错误/额度/过期以彩色提示条区分，空闲与完成状态仅保留给读屏。答案为浅色阅读卡（左侧朱红条，17px/1.8），出现后自动滚动到答案。隐私与免责声明收为底部一行脚注，退出登录放在脚注旁。

## 贷款 demo 与解释契约

共享核心位于 docs/.vuepress/lib/loan/，主页适配器 loan.mjs 使用 JPY 示例和独立输入验证。默认 JPY 50,000,000 / 1.5% / 35 年；金额 JPY 1–10,000,000,000、整数日元，年利率 0–20%，期限 1–50 整数年。采用固定名义年利率、按月末还款、等额本息/等额本金，不含费用、税收、提前还款或变动利率。不逐期舍入，末期结清；显示保留分位。完整日元工具见房贷规格。主页复用 MortgageChart 的 compact 模式，横轴为经过年数，只有一张月供图；无视图管理、日期选择器或完整表格。方向键逐期查看，交点只说明月供关系反转。

年限滑块/加减、更多金额和利率参数、重置、单张月供图、首月/总利息摘要使用同一结果。无效输入保留并明确标注上次有效结果；工具链接携带该有效结果。主入口“打开完整房贷比较”携带 amount/rate/months 到对应语言，示例解释为次级按钮。

内联解释复用既有 Cognito 登录和 JSON API，每日最多20次，登录或打开面板不会自动推理。保留三个预设问题、登录参数恢复、主动请求、取消、额度/失败/过期状态、参数变化后的旧答案提示及退出。关闭或卸载会取消等待；解释不能覆盖计算结果。此次仅统一面板边框、按钮和焦点样式，无认证、API或计算契约变更。真实服务验收见 ../ai-interpreter/validation.md，自动化使用受控浏览器夹具。

## 最终 Logo 几何规格

最终Logo统一命名`/logo.svg`，用于首页及全站导航。内外弧度对称，保留交叠切口；不保留方案或版本文件名。试验SVG及旧检查脚本仅留在忽略产物目录。

两道斜切口形成交叠丝带，保留厚实的轮廓。内外半环由同一组四分之一椭圆近似曲线镜像，过渡段使用端点切线及曲率约束；两切口为中心旋转配对的直线。整个带切口图形中心对称，内外半环左右/上下镜像对称，不要求带切口的整体左右/上下镜像。

几何参数以图形中心为原点：半环中心横坐标±337，外侧极值±679，内侧极值±514；外侧纵向极值±370，内侧±176。四分之一椭圆的贝塞尔常数`k=4(√2−1)/3`。中心过渡边界纵坐标±155，切线斜率1.42；两切口来自直线`y=1.43x−184.3`及其中心旋转副本与对应曲线的交点。按对称生成，未逐点手动调左右两侧。

过渡曲线的控制点距离由曲率约束计算：`p=337−(370−155)/1.42`，`r=337−(176+155)/1.42`；设外/内椭圆顶部曲率为κo/κi，中心切线控制距离分别为`qo=(370−155−1.5κo·p²)/1.42`、`qi=(176+155−1.5κi·r²)/1.42`。中心接点曲率为零，圆弧接点曲率匹配。沿切口交点拆分贝塞尔曲线，不改变原弧形。

最终路径16段三次贝塞尔加2条切口直线，单色#B63824、透明背景，无遮罩、位图或外部依赖。14处非切口连接通过切线与曲率连续性检查，切口端点刻意保留尖角。复现：`node scripts/check-logo-geometry.mjs`。

## 全站导航与侧栏

首页、文章和工具使用同一固定64px页眉：Logo返回当前语言首页；工具（房贷、日本税务）、笔记（编程、算法、机器学习、杂项）、工程、联系；语言切换始终可见。工程/联系指向对应语言首页区块，并为固定页眉预留滚动空间。GitHub保留于首页联系区，文章编辑链接不变。

中文笔记菜单中的未翻译内容明确标注“英文”；机器学习和工具进入对应语言路径。语言切换优先对应页面，缺少翻译时复用默认主题的语言首页回退。筛股器接入全站菜单，但仍不作为可用工具推广。

手机（719px及以下）统一侧栏：上半部“全站导航”，有文章目录时显示独立“文章目录”分组；桌面侧栏仅呈现文章目录。关闭侧栏不可聚焦；展开时限制焦点和背景滚动，Escape关闭并返回菜单按钮，点击链接或遮罩可关闭。桌面与手机断点切换会清理展开状态。

目录配置覆盖现有文章：英文补齐树结构补充、Java、狼人杀代码示例和交叉熵；中文补齐项目分类。工具和首页不显示文章目录，不为没有翻译的文章制造中文路由。目录当前页高亮与章节联动复用默认主题；长目录会滚动使当前文章条目可见。404继续保留简化错误说明与返回首页入口。

税务工具不显示“可体验/Try it”阶段标签，首页使用“打开税务计算器/Open the tax calculator”，导航直接使用工具名称。税务页首屏明确2025工资收入/2026住民税；筛股器继续显示规划中。
