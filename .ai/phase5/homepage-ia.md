## 3. 首页贷款体验：最小完整操作

### 输入与图表

- 只比较固定利率、按月偿还的等额本息与等额本金；暂不包含税费、保险、提前还款、浮动利率或真实银行产品。控件附近简短写明示例假设，不把假设埋在页脚。
- 初始仅突出年限滑块，并提供数值输入或加减按钮；金额与年利率收进“更多参数”。参数的数值范围、初值和计算舍入在设计规格/工具规格中确定，本阶段不展示未经计算的货币数值。
- 默认图表为月供随时间的变化，两种方式始终同屏，以线型、文字图例和颜色共同区分。选中某年时可查看该节点数值；触摸与键盘都能完成同等操作，不依赖 hover。
- 摘要同时列出每种方式的首月、末月月供和总利息。等额本金不以单一“月供”数值掩盖其变化。
- 每次有效输入立即重算图表和摘要；无效输入显示字段错误并暂留上一次有效结果，明确它未更新，不请求 AI。
- “查看数据”展开图表对应的可读表格；“重置”恢复示例输入。没有 JS 时呈现同一示例的静态图表、摘要、假设和说明，交互控件不伪装为可用。

返済方式用语依据住宅金融支援机构的 [元利均等返済・元金均等返済说明](https://www.flat35.com/loan/lineup/kinto/index.html)（2026-09-05 查阅）。该来源只用于理解比较对象，不表示采用其贷款产品条件、利率或资格要求。正式数值逻辑需在原型阶段单独核验。

### 从操作到解释

1. 访客修改年限，图表与摘要更新；焦点停留在操作控件，不跳转、不自动弹出解释。
2. 点击“解释差异”，展开面板，呈现当前条件和三个推荐问题：为什么月供曲线不同、期限变化影响了什么、这个例子有哪些假设。
3. 选择问题后，以本次输入与计算结果的快照生成模拟解释。面板持续标明“示例解释 · 未连接 AI”；不使用“实时 AI 分析”等措辞。
4. 回答引用本页实际指标，例如首月还款、总利息或还款前期。引用是普通按钮：用户主动点击才定位、高亮对应指标；取消高亮后数值仍可正常阅读。
5. 用户可继续输入问题。mock 只支持已定义的意图，其它输入明确说明当前预览支持的范围并展示推荐问题，不编造回答。
6. 参数再次改变时取消尚未完成的回答；已有回答标为“对应上一次条件”，提供“按当前条件更新”。不在拖动过程中连续发起解释。

计算模块是数值真值来源；解释仅消费输入、计算结果、假设和 locale，不能覆盖数值。前端 mock 不需要联网，未来真实 adapter 另接后端；本阶段只定义职责，不选模型、协议或服务商。

## 4. AI 状态、页面联动与降级

| 状态 | 页面表现 | 用户操作 / 转移 |
| --- | --- | --- |
| 收起 | 图表旁的“解释差异”，无聊天遮罩 | 打开后显示欢迎与推荐问题 |
| 就绪 | 当前条件、推荐问题、输入框、示例解释标识 | 空输入不发送；选问题或发送支持的输入进入生成 |
| 生成中 | 模拟流式文本、取消按钮 | 取消保留已显示内容并标“已取消”；关闭也取消任务 |
| 完成 | 回答、指标引用、继续提问 | 引用按钮定位指标；可关闭或再次提问 |
| 条件已变更 | 旧回答明确标识，不当成当前结论 | 用户主动更新；若生成中则先取消旧任务 |
| 范围外 | 简短说明与支持的问题 | 修改输入或选推荐问题 |
| 网络错误 / 超时 / 限流预览 | 清晰的状态文本与恢复操作；计算器仍可用 | 错误/超时允许重试；限流按模拟状态提示稍后重试，不承诺服务恢复时间 |

网络、超时与限流仅在隔离原型的审阅状态中由 fixture 触发，不给正常访客随机制造故障；不把开发用状态切换器带进正式用户流程。

键盘打开后焦点移到面板标题或第一个推荐问题，关闭返回触发按钮。面板是内联区域，不使用 modal，也不锁住整个页面焦点；Esc 仅在面板内部作为关闭快捷键。显式定位数据时将焦点交给对应标题/数据项，不在流式输出期间抢焦点。

流式文本不逐字广播给屏幕阅读器；只礼貌播报开始、完成、取消或失败。reduced-motion 下不做平滑滚动、曲线插值或打字效果，直接呈现对应状态。SSR 始终输出身份、工具状态、工程内容、笔记与联系链接，不再把核心正文放入 ClientOnly。

语言切换保持对应中英文主页可达。第一版允许重置贷款示例与解释，明确不保证跨语言保存会话；两种语言使用同一场景和计算规则。全部按钮、状态和解释都需本地化，不能复用旧主页未翻译的 Recent Work / View。
