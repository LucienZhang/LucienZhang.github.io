## 复现

Node >=22.18，按 package-lock 安装。

- `npm run verify`：生产构建、内部链接、路由与关键产物、安全、9路由浏览器冒烟、主页交互及独立数值检查、房贷和税务回归。
- `HOMEPAGE_CAPTURE=1 npm run check:home`：中英主页检查及截图；默认不写截图。包含 logo 几何检查。
- `node scripts/check-mortgage-browser.mjs`：房贷双语交互、视图、焦点、SSR及响应式。
- `TAX_FULL_AUDIT=1 TAX_LOCALE=en node scripts/check-japan-tax-browser.mjs`（再独立运行 zh）：税务输入、帮助、来源、结算、语言、SSR及布局。避免两次运行争用前台鼠标。
- `PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs PREVIEW_ORIGIN=http://127.0.0.1:4387 node scripts/check-stock-screener-browser.mjs`：筛股器专项；先启动构建目录 HTTP 服务器，使用机器上的 Playwright，不新增项目依赖。
- `node scripts/measure-homepage-assets.mjs` / `HOMEPAGE_HEADED=1 node scripts/measure-homepage.mjs`：体积与可见页面性能采样。LCP 必须为正有限值，hidden/null 结果无效。

浏览器检查需要本地监听权限和 Chrome/Chromium。截图、原始报告和临时检查均在忽略目录 `.ai/artifacts/`；截图不是自动差异测试基准。
