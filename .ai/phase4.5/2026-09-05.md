该修复通过 PR #9 合并后，Actions run `33944202769` 再次证明 notebooks、构建、链接、产物、安全检查和全部浏览器断言成功，但 Ubuntu 上的 Chrome 辅助进程在主进程退出后仍会写入 profile，10 次删除重试耗尽后再次触发 `ENOTEMPTY`。后续修复保留主动停止 Chrome 和 profile 删除重试，但只将 `ENOTEMPTY`/`EBUSY` 这两类暂态清理错误降级为 warning；权限、路径等其他文件系统错误仍会使测试失败。profile 位于操作系统临时目录，GitHub runner 本身是一次性环境，因此残留目录不构成部署产物或持久资源泄漏，也不应覆盖已经成功的功能断言。
