# Phase 3 UI 依赖收敛报告 — 2026-09-04

Phase 3 只处理 UI 基础依赖：移除 Bootstrap 4、将 Ant Design Vue 3 升级到 4，并更新其自动导入链。主页视觉重做、工具页、chatbot、文章 `@tab` 迁移以及首页 HTML/hydration 修复均不在本阶段。

## 版本与兼容性结论

实施前于 2026-09-04 核对了 npm metadata 和官方迁移说明。最终矩阵为：

| 依赖 | Phase 2 | Phase 3 | 选择依据 |
| --- | --- | --- | --- |
| Vue | `3.5.42` | `3.5.42` | 保持 VuePress 兼容矩阵，不单独变更 |
| Vite | `8.2.2` | `8.2.2` | 仍由 `@vuepress/bundler-vite` 管理 |
| Ant Design Vue | `3.2.15` | `4.2.6`（精确版本） | v4 支持 Vue 3，并迁移到 CSS-in-JS |
| `@ant-design/icons-vue` | v3 链路 | `7.0.1`（传递依赖） | 由 Ant Design Vue 4.2.6 的依赖范围解析 |
| `unplugin-vue-components` | `0.22.12` | `32.1.0`（精确版本） | 当前版本支持 Vue 3 及 Vite/Rolldown 插件链 |
| Bootstrap | `4.6.2` | 已删除 | 仅 MNIST 使用少量 grid/button Sass，无升级到 Bootstrap 5 的收益 |

Ant Design Vue v4 的官方 changelog 明确记录了 Less/CSS 到 CSS-in-JS 的迁移、CSS 文件移除，以及 Modal `visible` 到 `open` 的 API 调整：[Ant Design Vue changelog](https://github.com/vueComponent/ant-design-vue/blob/main/CHANGELOG.en-US.md)。`unplugin-vue-components` 官方仓库列出 Vite/Rolldown 支持，Ant Design Vue resolver 的调用方式保持可用：[unplugin-vue-components](https://github.com/unplugin/unplugin-vue-components)。

没有引入 Ant Design 的全局 `reset.css`。这样可以避免 reset 样式污染自定义主页和 VuePress 默认主题；组件样式由 resolver 以 CSS-in-JS 方式按需引入。

## 实施内容

- `ant-design-vue` 固定为 `4.2.6`，`unplugin-vue-components` 固定为 `32.1.0`，删除 `bootstrap`。
- resolver 显式设置 `importStyle: "css-in-js"`。新版 resolver 的默认样式模式仍可能生成旧式 `style/css` 路径，而 Ant Design Vue v4 已删除这些 CSS 文件，因此不能依赖默认值。
- 首页二维码 Modal 改用 `open`，没有改变自定义主页布局或视觉。
- MNIST 保留原 2/8/2 列宽、55px 控制区、按钮颜色、hover、canvas 和识别逻辑；新增 `focus-visible`，并彻底移除 Bootstrap class 与 Sass partial。
- 本阶段没有建立全站 design-token 系统。MNIST 只把原 Bootstrap 视觉值局部固化；全站颜色、字体、间距、圆角、阴影和动效应随 Phase 5 主页设计一起确定，避免在保持现状的升级阶段提前改变视觉语言。
